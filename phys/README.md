# Happy Theta — plain HTML/CSS/JS

A framework-free rewrite of the SvelteKit app. No build step, no dependencies.

Open `index.html` in a browser (double-click works), or serve the folder with any static server.

```
index.html                  home
figures/*.html              Free Body, Motion, Energy diagrams, Graph Maker, Advanced Graph Maker
cv-apps/gif-maker.html      GIF Maker
css/style.css               all styles (replaces Tailwind + Flowbite)
js/core.js                  navbar, toolbar, editable labels, canvas stage, grid logic, PNG export
js/<tool>.js                one file per tool
js/gif-encoder.js           GIF encoder (replaces gifshot)
js/math-expr.js             math expression parser used by the Advanced Graph Maker
assets/                     logo and favicon
```

## Deploying

This folder is served at `/phys/` on the website. Zip the *contents* of this folder and unzip them into the server's `phys/` directory. Every link and asset path is relative (each page sets `data-root`), so it works from any folder name, but the site must be reached with a trailing slash (`/phys/`, not `/phys`), which nginx and Apache do by default for directories.

## Accounts (needs the server)

`account/login.html`, `message.html` and `dashboard.html` sign users in and talk to the API at
`api/` (relative to this folder, so `/phys/api/` on the website). The API is the Node app in
`../server/`; see `server/README.md` for setup. The other tools don't use it and still work
offline. These pages ship in the same zip; without the server running they just show
"Can't reach the server".

## Theta Scheduler (teacher course planner)

`teacher/scheduler.html` — plan a course day by day. Not in the navbar yet; link to it directly.
Works offline: every change autosaves to this browser (localStorage, tool `scheduler`), and
**Download** / **Open…** move a course as a `name.scheduler.json` file in the usual envelope.

```
teacher/scheduler.html      the page
css/scheduler.css           its styles
js/scheduler-model.js       data model + pure logic (A/B days, lane packing, shift, coverage); also runs in Node
js/scheduler.js             app shell, saving, undo, calendar, editor panel, activity bank, dialogs
js/scheduler-plan.js        semesters, holiday suggestions, spreading topics over meetings, templates, catch-up (also runs in Node)
js/scheduler-wizard.js      School calendar wizard, Templates dialog, Catch up dialog
js/scheduler-library.js     Library tab: search/pull shared activities, share (merge) your own (needs the server)
js/scheduler-seed-waddell.js the Waddell sequence (generated by ../tools/build-waddell-seed.js — edit that)
js/scheduler-views.js       Objectives outline editor, Dashboard (content map), Settings
js/scheduler-seed-ap1.js    AP Physics 1 framework + Unit 0 + science practices + quiz bank (seed for new courses)
```

- Days: weekdays from term start to end. Settings → Schedule (or the calendar's **A/B schedule…** button)
  sets how each weekday becomes A, B or no class: a quick Mon–Fri pattern (A / B / alternates / no class,
  or "every school day alternates"), and Google-Calendar-style repeat rules (type, every N weeks, weekdays,
  start/end dates, class length). Lower rules win; days off and single-day changes win over all rules.
  Alternating rules switch either each time they meet (a day off doesn't count) or every calendar week.
- Class length: a course default, optional per rule, optional per day (early release). Meeting rows show
  planned in-class minutes / class length; an in-class activity's time is spread over the meetings it spans.
  Unit and topic panels show meetings, class minutes and minutes planned.
- Calendar columns: Date, Day, Type, Unit, Topic, In class, the teacher's columns (Settings → Calendar
  columns: an activity goes in the first column whose types/assessment match), Other.
- Blocks span start row → end row; overlapping blocks get side-by-side lanes. Drag to move, drag the
  bottom edge to change the end date, click an empty cell to add. Ctrl+Z / Ctrl+Y undo and redo.
- Shift dates… moves everything on/after a date by N class meetings (not calendar days).
- Dashboard counts, per objective: Presented (activity types whose tag "counts as" presentation),
  Formative and Summative (the activity's Assessment field). "+n" = linked only to a broader objective.
- The seed text includes College Board course-framework wording; the repo is public.
- **School calendar…** (also New course): a 4-step wizard — school year and second-semester start; days off
  (with suggested common US holidays to check against the district calendar); meets on, class length and the
  A/B pattern with a preview; and optionally laying out a template over the year, a semester or custom dates.
- **Templates…**: the built-in framework template (units at the spreadsheet's lengths, topics splitting each
  unit, each quiz at the end of the last topic it covers), and templates saved from a course (`schedtemplate`
  tool, `name.schedtemplate.json`). Activities are stored relative to their topic in class meetings, so they
  stretch with it. Applying can replace what's in the range (fixed-date activities stay; topics of units not
  being laid out, e.g. the end of a unit from last semester, stay and the layout starts after them).
- **Catch up…**: pick the most recently finished topic and the date; later topics are squeezed into the rest
  of the semester, spread over the rest of the year or up to a date (proportional to their planned lengths),
  or pushed later keeping their lengths. Activities move with their topics; "Fixed date" activities don't.
  A preview table shows old → new dates before anything changes. Undo works.
- **Library** tab (teacher account + the server): search shared activities by words, topic/objective, type,
  assessment, interaction, in/out of class and minutes; add one to the bank or onto a date. The copy is yours
  to change. **Share my activities…** merges your course's activities into the library (new ones are added,
  ones you shared before are updated, edited copies of other teachers' activities become your own version).
  Copies show "update available" when the original changes. Objectives travel as AP codes, so an activity
  shared from one sequence links to the right objectives in another.
- **Waddell sequence** (default framework for new courses): the AP Physics 1 LOs/EKs reorganized into
  Unit 0, 1 (1D uniform motion), 2a (accelerating motion), 2b (1D non-equilibrium), 3 (2D motion),
  4 (rotation), plus "Not yet placed" (SHM, fluids). Nodes have a `kind` (unit/topic/subtopic/lo/ek/detail);
  an LO split across topics appears in each place with only its own EKs (marked partial). To change the
  sequence, edit `SEQUENCE` / `QUIZ_TOPIC` in `tools/build-waddell-seed.js` and run
  `node tools/build-waddell-seed.js` from the repo root.
